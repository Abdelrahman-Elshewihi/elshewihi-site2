# Abdelrahman Portfolio — Organized

## إزاي تضيف مشروع جديد (الطريقة السريعة)

افتح `data/projects.json` بس، وضيف عنصر جديد جوه `"items"` بالشكل ده:

```json
{
  "id": "معرف-فريد-بالانجليزي",
  "featured": false,
  "image": "images/xxx.jpg",
  "tags": ["logo"],
  "category": { "ar": "التصنيف بالعربي", "en": "Category" },
  "title": { "ar": "اسم المشروع", "en": "Project name" },
  "desc": { "ar": "وصف قصير.", "en": "Short description." },
  "problem": { "ar": "المشكلة اللي بيحلها.", "en": "The problem it solves." },
  "did": { "ar": "اللي عملته.", "en": "What you did." },
  "tech": ["Photoshop", "Illustrator"],
  "price": { "value": "75", "currency": "USD" }
}
```

**قيم `tags` المتاحة** (تحدد تحت أي فلتر يظهر المشروع في قسم الأعمال):
`logo` | `card` | `website` | `video` | `app` | `voice`

## إضافة مشروع فيديو (مونتاج)

نفس الطريقة، بس بدل `image` (أو معاها)، ضيف:
```json
"video": "كود فيديو اليوتيوب فقط",
"videoVertical": true
```
- خد الكود من رابط اليوتيوب: `youtu.be/CODE` أو `youtube.com/watch?v=CODE` أو `youtube.com/shorts/CODE`
- `videoVertical: true` لو الفيديو Shorts (عمودي) — بيخلي المشغل طولي بدل عريض
- لو مش هتحط `image`، الموقع هياخد صورة غلاف تلقائي من يوتيوب نفسه — مش لازم ترفع صورة بنفسك

## التعديل السريع

| عايز تعدل إيه؟ | افتح الملف ده |
|---|---|
| مشاريع (إضافة/حذف/تعديل/أسعار) | `data/projects.json` |
| النصوص والترجمة (عربي/إنجليزي) | `js/main.js` → داخل `I18N` |
| التصميم والألوان | `css/style.css` |
| حجم الخطوط | أول `css/style.css` تحت `EASY EDITS` |
| التفاعلات (الفلتر، الفيديو، الـmodal) | `js/main.js` |

## شكل العرض

- المشاريع تظهر في عمود واحد طولي بعرض موحّد (زي شكل الموبايل بالظبط، على كل الشاشات)
- فوق الأعمال فيه فلتر تصنيفات (الكل/لوجوهات/كروت/مواقع/مونتاج/تطبيقات/فويس أوفر)
- أي مشروع فيديو بيظهر عليه أيقونة ▶ على الغلاف، ولما تدوس عليه بيشغل الفيديو مباشرة جوه نافذة التفاصيل

## التواصل

- WhatsApp يفتح المحادثة مباشرة بدون رسالة جاهزة.
- LinkedIn يفتح صفحة الملف الشخصي في تبويب جديد.
- الأسعار بالدولار الأمريكي (USD).

## المؤشر

على أجهزة الماوس يظهر المؤشر التفاعلي الدائري فقط، بينما يظل المؤشر الطبيعي متاحًا على الأجهزة اللمسية.

## مهم

الموقع يحتاج تشغيله من سيرفر محلي أو استضافة فعلية لكي يعمل `fetch("data/projects.json")` بشكل موثوق؛ فتح `index.html` مباشرة عبر `file://` قد يمنع تحميل JSON في بعض المتصفحات.

## الشات بوت الذكي (AI Chat Widget)

الموقع فيه شات بوت (زرار عايم في زاوية الشاشة) بيرد على أي سؤال من زوار الموقع عن عبدالرحمن — شغله، مهاراته، أسعاره — باستخدام الذكاء الاصطناعي **مجانًا بالكامل** (عن طريق Groq).

### إزاي تشغّله (خطوة واحدة، مرة واحدة بس)

1. اعمل حساب مجاني على [console.groq.com](https://console.groq.com) (بدون فيزا).
2. من صفحة **API Keys** جوه الموقع، اعمل key جديد وانسخه.
3. روح لمشروعك على Vercel → **Settings → Environment Variables**، وضيف متغيّر اسمه بالظبط:
   - **Name:** `GROQ_API_KEY`
   - **Value:** الـ key اللي نسخته
4. اعمل **Redeploy** للمشروع من Vercel (أي تعديل بسيط وعمل push كفاية، أو زرار Redeploy مباشرة من الداشبورد).

كده الشات بوت هيشتغل على طول. مفيش أي كارت ائتمان مطلوب، والاستخدام هيفضل مجاني طول ما موقعك مش بياخد آلاف الأسئلة يوميًا (حد Groq المجاني كام آلاف رسالة في اليوم، أكتر من كفاية لبورتفوليو شخصي).

### إزاي تعدّل اللي الشات بوت بيعرفه عنك

كل المعلومات اللي الشات بوت بيرد بيها موجودة في **`data/profile.json`** — افتحه وعدّل أي حاجة (النبذة، الخدمات، سياسة الأسعار، لينكات التواصل...) وهيتحدث الشات بوت أوتوماتيك من غير أي كود إضافي.
معلومات المشاريع والأسعار بياخدها الشات بوت مباشرة من `data/projects.json` (نفس الملف اللي بتضيف بيه المشاريع)، فمش محتاج تكررها في مكان تاني.

⚠️ استثناء واحد بس: لو غيّرت نسبة الخصم (`percent`) في `js/main.js` جوه `PROMO`، لازم تروح تغيّرها كمان في `api/chat.js` جوه `PROMO_MIRROR` بنفس الرقم، عشان الشات بوت يقول للزوار السعر الصح.

### التجربة محليًا قبل الرفع

الشات بوت محتاج سيرفر Vercel عشان يشتغل (مش بيشتغل بفتح `index.html` مباشرة). لو عندك [Vercel CLI](https://vercel.com/docs/cli) مركب، شغّل الأمر ده جوه فولدر المشروع:
```
vercel dev
```

## لوحة التحكم (Admin CMS)

فولدر `admin/` فيه لوحة تحكم بصرية (Decap CMS) لإضافة/تعديل المشاريع من غير ما تلمس الكود مباشرة، لما تفعّلها حسب `دليل-تفعيل-لوحة-التحكم.md`. اللوحة بتدعم كل الحقول شاملة الفيديو والتصنيفات.
